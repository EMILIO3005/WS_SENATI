# WebService
Esta aplicacion, utiliza como entorno de desrrollo para acceder y gestionar los datsos desde Mysql y servirlos a traves de la API REST en formato JSON. Sera utilizado mas adelante desde una APP en Android Studio


## Requerimientos
- NodeJS
- MySQL
- ThunderClient/Postman


### Base de datos
Restaure la DB, tabla y registros desde el archivo **database.sql**. Antes de continuar verifique que este proceso se realizo correctamente


### Despliege
1. Clone el repositorio:

``` shell
git clone https://github.com/usuario/mi-proyecto.git
```
2. Restaure node_modules:
```shell
npm install
```
3. Ejecute el servidor local: 
```shell
npm run dev
```
